> **RouteFlow** — це вебдодаток для інтерактивного планування та математичної оптимізації автомобільних маршрутів (розв'язання транспортної задачі та задачі комівояжера TSP) реальними дорогами з урахуванням витрат пального, необхідності дозаправок на АЗС, бази відділень Нової Пошти та інтерактивною анімацією руху машинки.

---

## 📖 Що це таке?

Коли водієві, кур'єру або мандрівникові потрібно відвідати декілька точок (наприклад, 5 чи 10 адрес у місті або по всій Україні), хаотичний об'їзд забирає зайві години, кілометри та сотні гривень на пальне.

**RouteFlow вирішує цю проблему автоматично:**
1. Ви обираєте точки кліком по карті або знаходите потрібні відділення (наприклад, *«нова пошта хутірське»* чи маркети *«АТБ»*).
2. Алгоритм розраховує матрицю відстаней по **реальній дорожній мережі** та знаходить **математично найкоротший або найшвидший порядок об'їзду**.
3. Програма враховує характеристики вашого авто (витрату на 100 км, ємність бака, поточний залишок) і **попереджає, де саме на маршруті знадобиться заїхати на АЗС** для дозаправки.
4. Після розрахунку ви можете запустити **симулятор поїздки**: машинка повертається за поворотами дороги, рівень бензину в баці тане в реальному часі, а при заїзді на АЗС відбувається анімація заправки.
5. Готовий оптимізований маршрут можна в один клік відкрити в **Google Maps** або відсканувати **QR-кодом** з екрана для миттєвої GPS-навігації на iPhone / Android.

## 🌟 Ключові можливості

### 1. 🛣️ Оптимізація реальних доріг (TSP Engine)
- **Точна матриця OSRM**: враховує реальні автомагістралі, розв'язки, швидкісні обмеження та односторонній рух (замість прямих ліній по повітрю).
- **Математичний оптимум**: точний Held-Karp алгоритм для $N \le 10$ та 2-Opt локальний пошук для великої кількості точок.
- **Режими поїздки**:
  - *Кільцевий* (повернення назад на старт).
  - *Фіксований фініш* (від заданого Старту до обраного Фінішу).
  - *Довільний фініш* (алгоритм сам знаходить найвигіднішу кінцеву точку).
  - *Точний порядок зі списку* (збереження власної послідовності).

### 2. 🎨 Різнокольорові ділянки маршруту
- Кожен відрізок між послідовними зупинками має свій колір (1➔2 синій, 2➔3 жовтий, 3➔4 зелений, 4➔5 фіолетовий тощо).
- У списку зупинок кожна ділянка підсвічується тим же кольором для максимальної наочності.

### 3. ⛽ Розумний розрахунок пального & Дозаправки
- Пресети для різних типів транспорту: 🚗 Легковий, 🚙 Кросовер, 🚐 Бус, 🚛 Вантажівка, 🏍️ Мотоцикл, ⚡ Електромобіль.
- Налаштування об'єму бака, початкового рівня та резервного залишку.
- **Пульсуючі маркери АЗС `⛽` на карті**: точно показують, на якому кілометрі траси пальне впаде до резерву, скільки літрів треба долити та скільки це коштуватиме.
- Кнопка **«Знайти АЗС поруч»** підтягує реальні найближчі заправки (ОККО, WOG, Shell) біля точки заправки.

### 4. 🧠 Розумний пошук (Нова Пошта, супермаркети, АЗС)
- **Нова Пошта**: офіційний API з усіма відділеннями та поштоматами України (*наприклад: «нова пошта хутірське», «нова пошта львів 12»*).
- **Пошук мереж у зоні карти**: введіть *«АТБ»*, *«Сільпо»*, *«ОККО»*, *«Аптека»* — додаток знайде всі заклади у видимій області карти.
- **Групове додавання**: кнопка *«➕ Додати всі»* заносить усі знайдені маркери до маршруту одним кліком.

### 5. ✋ Зручний Drag & Drop у панелі
- Зміна черговості точок у списку перетягуванням мишкою або пальцем.
- Кнопки `🟢 Старт` та `🏁 Фініш` для миттєвого призначення початкової чи кінцевої зупинки.

### 6. 🎮 Маршрутний плеєр-симулятор
- Анімація руху машинки з поворотом іконки за вигинами дороги.
- Живий індикатор пального у баці зі зміною кольору (зелений ➔ жовтий ➔ червоний).
- Режим слідування камери за рухомим автомобілем.
- Регулювання швидкості симуляції: `1x`, `3x`, `8x`, `20x`.

### 7. 📱 100% Адаптація під мобільні телефони
- Повноекранна карта на смартфонах.
- Зручна нижня висувна шторка (Bottom Drawer) для налаштувань.
- Вбудована функція швидкого відкриття на телефоні через локальний Wi-Fi та QR-код.

## 🏗️ Архітектура та стек технологій

```text
[ Клієнт (Браузер / Телефон) ]
       │
       ▼
[ Leaflet.js + Google Maps Tiles (Roadmap, Satellite, Hybrid) ]
       │
       ▼  (REST JSON API)
[ Flask 3.1 Backend / Vercel Serverless Function (@vercel/python) ]
       │
       ├─► [ OSRM API ] ── Матриця реальних доріг та геометрія відрізків
       ├─► [ Nova Poshta API v2.0 ] ── База всіх відділень/поштоматів України
       ├─► [ OSM Nominatim ] ── Геокодинг адрес та мережевих закладів (АТБ, АЗС)
       ├─► [ TSP Solver ] ── Динамічне програмування Held-Karp + 2-Opt
       └─► [ Fuel Engine ] ── Симуляція витрати пального та пошук точок АЗС
```

## ⚡ Швидкий запуск на комп'ютері

### Спосіб 1: Подвійний клік у Finder (macOS)
Просто двічі клікніть на файл **`run.command`** у папці проєкту.

### Спосіб 2: Через термінал
```bash
# Встановлення залежностей (якщо запускаєте вперше)
pip3 install -r requirements.txt

# Запуск сервера
python3 app.py
```
Відкрийте у браузері: [http://127.0.0.1:5000](http://127.0.0.1:5000)
